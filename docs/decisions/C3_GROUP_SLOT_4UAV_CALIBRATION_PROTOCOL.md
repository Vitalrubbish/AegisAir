# C3-GroupSlot 四机中等密度 Calibration 协议（v2）

本协议是独立的四机闭环扩展，不修改极端终点交换的任何 No-Go。

v1 的两次启动均未进入有效实验：一次遥测未就绪，另一次四号机在超出已验证
工作区的复位途中未稳定。随后一个走廊几何开发运行虽完成了 60 s 轨迹，但外层
会话没有生成 `summary.json` 与完整性清单，因此同样只保留为无效工件。v2 在
任何有效 calibration 前冻结下面的已验证工作区走廊，并使用新协议标识。

- 四架机保持同高度，使用两条近邻中心走廊和两条外侧走廊；
- 四个终点均未被其他无人机初始占用；
- C3 冻结两组兼容航路 `[2,3] → [4,5]`；
- 第一组 `[2,3]` 在 `y=+/-0.8 m` 的近邻走廊通行，第二组
  `[4,5]` 在 `y=+/-3.0 m` 的外侧走廊通行；
- 组间不重叠；冻结等待点与第一组起点的最近间距为 `3.8 m`；
- RA、`d_safe`、20 Hz、60 s、PX4/SITL 和完成锁存要求均不降低；
- C3 只发任务级目标/速度比例，RA 仍过滤每个实际动作。

本 smoke 通过后才冻结五个新 seed 的 qualification。论文定位仅为
“four-UAV moderate-density closed-loop scalability validation”，不写成终点交换或
一般化四机安全。
